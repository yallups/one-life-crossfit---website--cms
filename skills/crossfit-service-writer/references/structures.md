# Content Structures

## Service page (long-form)
1. Hero headline + subhead + CTA
2. What it is (1–2 short paragraphs)
3. Who it’s for (bullets)
4. What to expect (class flow + coaching support)
5. Outcomes you can expect (non-guaranteed, practical)
6. What’s included (bullets)
7. Schedule / how to start
8. Pricing overview or “talk to us”
9. FAQs (5–8)
10. Final CTA

## Membership overview (short-form)
- 2–3 sentence overview
- 3–6 bullets for inclusions
- 1–2 lines on flexibility/commitment
- CTA

## Comparison table (bullet-ready)
- Plan name
- Best for
- Included classes/week
- Perks (open gym, specialty, nutrition)
- Price range
